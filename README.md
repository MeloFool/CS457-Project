Game: Penalty Shootout
Author: Luke Lowther
Date: 10/18/2026

Penatly Shootout is a round based command line interface game that mixes luck with attempting to read your opponets next move.

Roles: The first player to connect will be the first "shooter", second to connect will be the "keeper", roles swap every kick.
Kicks: Both the shooter and keeper will pick left/right/center. Neither player sees the others choice until both are locked in
Scoring: The shooter will score 1 point if the keeper blocked a different direction. If the directions match, no point is awarded
Rounds: Each player shoots and blocks once (two kicks in total) to make up a round
Winning: After five rounds, the player with more goals wins
Ties: If tied after 5 rounds, the game continues one round at a time until one player scores and the other does not. There are no draws
Disconnects: If a player disconnects mid-match, the remaining player wins by forfeit.
